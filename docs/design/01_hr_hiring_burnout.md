## 1. 핵심 스탯 (직원 1인당)

| 스탯 | 범위 | 설명 |
| :--- | :--- | :--- |
| `skill` | 1~100 | 직무 숙련도. 직군 보너스에 곱연산 |
| `morale` | 0~100 | 사기. 30 미만이면 효율 -30%, 10 미만이면 퇴사 판정 시작 |
| `burnout` | 0~100 | 번아웃. 야근/장애 대응 시 누적. 80 이상이면 병가·퇴사 확률 급증 |
| `loyalty` | 0~100 | 충성도. 스톡옵션·창업멤버 여부로 상승, 이직 제안 방어력 |
| `salary` | 원/월 | 월급. 매 게임월(60초) 정산 |
| `stockOption` | 0~10% | 부여 지분. 지분 희석과 연동 |

### 매달 정산 공식
```
morale += (회사 분위기 보정) - (burnout × 0.1) + (급여 만족도)
급여 만족도 = (salary / 시장가) - 1.0  → ×20 보정 (시장가 대비 20% 낮으면 -4/월)
퇴사 확률(월) = max(0, (40 - morale) × 0.8% + (burnout - 70) × 1.2% - loyalty × 0.3%)
```

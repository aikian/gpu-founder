# 🎤 정부지원사업 · VC 피칭 질의응답 미니게임

> 지원사업/투자 유치를 단순 클릭이 아니라 **심사위원 압박 면접 RPG**로 구현.

---

## 1. 진행 규칙

1. **서류 평가** — 회사 지표(TFLOPS, 매출, 직원 수, 업력)로 자동 판정. 컷 통과 시 발표평가 진출.
2. **발표 평가** — 심사위원 3명이 번갈아 총 **5문항** 질문 (아래 10문항 풀에서 랜덤).
3. 각 문항마다 답변 3종 중 선택:
   * 🔬 **기술적 답변** — 정직 + 근거. 회사 지표가 받쳐줘야 고득점
   * 🎭 **블러핑/과장** — 즉시 고득점 가능하지만 `거짓말 게이지` 누적 → 사후 감사/실사 때 폭탄
   * 🙇 **솔직한 답변** — 안정적 중간 점수, 공무원 심사위원에게 가산점
4. **합격선**: 정부사업 70점 / VC 75점. 점수가 높을수록 지원금·밸류에이션 상승.

### 점수 공식
```
문항점수 = 기본점수(답변유형×심사위원 성향) + 지표보정
지표보정 = 질문 관련 지표 충족 시 +5, 미달 시 -10 (기술적 답변에만 적용)
최종점수 = Σ문항점수 × (발표 컨디션: 0.9~1.1, 전날 야근 시 0.9)
지원금 = 기본액 × (0.8 + (최종점수-합격선)/100)
```

## 2. 심사위원 3인

| 심사위원 | 성향 | 기술적 | 블러핑 | 솔직 | 특수 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| 🎓 **김 교수** (KAIST 전산학과) | 기술 덕후, 수식 좋아함 | **+20** | -5 (간파 50%) | +10 | 블러핑 간파 시 해당 세션 -15 추가 |
| 💼 **박 심사역** (VC 수석) | 시장성·숫자·TAM만 봄 | +10 | **+18** | +5 | "그래서 매출은요?" 지표 미달 시 -10 |
| 🏛️ **이 사무관** (중기부 출신) | 규정·서식·예산집행 계획 | +8 | -10 | **+18** | 정부사업에서만 등장, 서식 미비 시 즉시 -20 |

> VC 피칭에서는 이 사무관 대신 **🦈 최 대표 (엑싯한 연쇄창업가)** 등장: 블러핑 +12 / 솔직 +15 / 기술 +10, "본인이 직접 코딩하세요?" 질문.

## 4. 거짓말 게이지 (Lie Meter)

| 누적 | 결과 |
| :--- | :--- |
| 1~2회 | 영향 없음 |
| 3~4회 | 사후 현장실사 확률 40%. 들키면 지원금 50% 환수 |
| 5회+ | 실사 확률 80%. 들키면 **전액 환수 + 정부사업 참여제한 3년** |
| 불법 답변(#3 블러핑) | 감사 시 **e나라도움 횡령 혐의 → 배드엔딩 트리거** |

VC의 경우 들키면: 후속 라운드 불가, 투자계약서 위반으로 **상환전환우선주(RCPS) 상환 청구** 이벤트.

# Game Dev Tycoon (게임 개발 타이쿤) 시스템 규칙 및 메커니즘 분석

> **출처:** 나무위키 `Game Dev Tycoon` 및 공식 위키 공략 분석

---

## 1. 게임 개요
* **개발사:** Greenheart Games
* **장르:** 비즈니스 시뮬레이션, 게임 개발사 육성
* **특징:** 타이쿤 장르에서 가장 대중적으로 성공한 3단계 거점 확장 및 슬라이더 배분 메커니즘 정립.

---

## 2. 3단계 공간 성장 루프 (Stage Progression)
1. **차고(Garage) 시대 (1인 창업):**
   * 자본금 $70k로 시작. 혼자서 기획/코딩/아트를 전부 처리.
   * 자금 100만 달러 돌파 시 다음 단계 해금.
2. **소형 오피스 시대 (팀 빌딩):**
   * 최대 4~6명의 직원을 채용하여 팀 구성.
   * 직군별 전문화, 직원 교육(Training), 자체 게임 엔진 개발 가능.
3. **대형 사옥 및 R&D 랩 시대 (대기업):**
   * 전용 연구실(R&D Lab)과 하드웨어 랩(Hardware Lab) 신설.
   * 자체 콘솔 게임기 개발, 대규모 MMO 서비스 운영, 게임쇼 부스 참가.

---

## 3. 핵심 슬라이더 배분 메커니즘 (Slider Allocation)
* 개발 단계는 3개 스테이지(각각 3개 항목, 총 9개 항목)로 나뉨:
  * Stage 1: 엔진 / 게임플레이 / 스토리&퀘스트
  * Stage 2: 대화 / 레벨 디자인 / 인공지능
  * Stage 3: 월드 디자인 / 그래픽 / 사운드
* **비중(Weight) 최적화 공식:**
  * 장르별로 요구하는 이상적인 비율이 숨겨져 있음 (예: 액션 게임은 그래픽과 게임플레이에 높은 비중, RPG는 스토리와 레벨디자인에 높은 비중).
  * 잘못된 곳에 시간을 낭비하면 리뷰 점수가 5점 이하로 폭락.

---

## 4. 우리 'GPU 타이쿤' 적용 포인트
* **슬라이더 기반 포트폴리오 배분:** 보유한 GPU 연산력(TFLOPS)을 [크립토 채굴], [AI 클라우드 스팟 렌탈], [자체 SaaS], [엔터프라이즈 장기계약]에 슬라이더로 % 분배하는 UI 직관성.
* **단계별 거점 점프:** 원룸 방구석(자취방) → 오피스텔 → 지식산업센터 → 전용 서버실 → 하이퍼스케일 데이터센터.
